# Changelog

## 0.1.3

- Include recent local Codex sessions missing from the task index and deduplicate by conversation ID when counting concurrent tasks.
- The firmware is unchanged from 0.1.2.

## 0.1.2

- Show the five-hour allowance and its hours/minutes reset countdown when Codex reports that window.
- Detect the weekly allowance by window duration so the layout for weekly-only accounts stays the same.

## 0.1.1

- Add a standalone Windows x64 tray executable and a merged firmware image for first-time flashing.
- Add download and flash instructions and four USB captures of the device interface.
- Keep compiled firmware diagnostics free of local build paths.

## 0.1.0

- First public Windows/Wi-Fi edition for the Waveshare 2.16-inch AMOLED board.
- Codex task activity, usage and reset information, customizable heading, and standby clock.
- Four orientations, charging indicator, original synthesized cues, and touch controls for brightness and volume.
- Windows tray app with login startup and recovery; incremental reading of long Codex session logs.
- Reproducible firmware build and board-specific flash instructions.
