# Security

Use the display and the Windows companion only on a trusted LAN. The HTTP API and settings page are not authenticated or encrypted. Do not expose TCP 8738 or the device web server to the Internet. Wi-Fi setup is available on the temporary password-protected hotspot.

Please report vulnerabilities through GitHub's private vulnerability reporting feature if enabled. Do not include account credentials, Wi-Fi passwords, firmware backups, or private Codex session logs in public issues.
